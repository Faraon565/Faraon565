## Проекты

### ◆ [Backend-сервис аренды](https://github.com/Faraon565/rental-service)

Backend-сервис на Go для работы с пользователями и бронированиями.

В проекте реализованы REST API, JWT-авторизация, работа с PostgreSQL, RabbitMQ и Docker Compose. Для мониторинга использовались Prometheus и Grafana.

**Технологии:** Go, PostgreSQL, RabbitMQ, Docker, REST API, JWT, Prometheus, Grafana

### ◆ [Система преобразования естественного языка в SQL](https://github.com/Faraon565/natural-language-to-sql)

Учебное приложение на Python, позволяющее формировать SQL-запросы по текстовому описанию пользователя.

Занимался логикой обработки запросов, генерацией SQL с использованием локальной языковой модели и визуализацией результатов.

**Технологии:** Python, SQL, SQLite, SQLAlchemy, Streamlit, Ollama, Pandas, Plotly

### ◆ [Коллекция почтовых марок на C++](https://github.com/Faraon565/stamp-collection-cpp)

Учебный проект на C++ для работы с коллекцией почтовых марок. В проекте использованы ООП, разделение программы на модули, работа с файлами и тестирование основных компонентов.

**Технологии:** C++, ООП, STL, CSV, Git

### ◆ [Анализ питания и тренировок](https://github.com/Faraon565/nutrition-training-analytics)

Командный проект на Python для обработки и анализа данных о питании и тренировках.

В проекте я занимался обработкой данных, частью логики редактирования, экспортом в Excel и настройкой отдельных элементов интерфейса.

**Технологии:** Python, Pandas, Matplotlib, Tkinter, OpenPyXL
