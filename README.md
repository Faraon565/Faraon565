## Проекты

◆ ### Backend-сервис аренды

Backend-сервис на Go для работы с пользователями и бронированиями.

В проекте реализованы REST API, JWT-авторизация, работа с PostgreSQL, RabbitMQ и Docker Compose. Для мониторинга использовались Prometheus и Grafana.

**Технологии:** Go, PostgreSQL, RabbitMQ, Docker, REST API, JWT, Prometheus, Grafana

◆ ### Система преобразования естественного языка в SQL

Командный проект, позволяющий формировать SQL-запросы по текстовому описанию пользователя.

Занимался backend-логикой обработки запросов, генерацией SQL с использованием LLM и RAG, а также визуализацией результатов.

**Технологии:** Python, SQL, PostgreSQL, LLM, RAG

◆ ### Проекты на C++ и Qt

Учебные проекты с использованием C++, ООП и Qt.

Работал с проектированием логики приложений, классами, наследованием, пользовательскими интерфейсами и отладкой программ.

**Технологии:** C++, Qt, ООП, Git

◆ ### Анализ питания и тренировок

Приложение для анализа пользовательских данных о питании и тренировках.

Работал с обработкой, фильтрацией и агрегацией данных, а также с построением графиков и статистики.

**Технологии:** Python, Pandas, NumPy
